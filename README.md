# Telco Customer Churn

Seminarski rad iz predmeta Uvod u nauku o podacima — predviđanje odliva
korisnika (customer churn) telekomunikacione kompanije.

## Struktura projekta

Analiza je organizovana kroz Jupyter sveske u folderu `notebooks/`,
hronološkim redosledom:

| Sveska | Sadržaj |
|---|---|
| `00_definisanje_problema.ipynb` | Kontekst, cilj i opis skupa podataka |
| `01_inicijalni_pregled.ipynb` | Prvi pregled, nedostajuće vrednosti, tipovi |
| `02_sistematske_greske.ipynb` | Provera logičke konzistentnosti podataka |
| `03_train_test_split.ipynb` | Podela na trening/test skup |
| `04_detekcija_anomalija.ipynb` | Detekcija outliera (IQR metoda) |
| `05_priprema_podataka.ipynb` | Feature engineering i enkodiranje |
| `06_iterativna_eda.ipynb` | Eksplorativna analiza i statistički testovi |
| `07_modeliranje_i_evaluacija.ipynb` | Modeli, cross-validacija, tuning |
| `08_zakljucak.ipynb` | Objedinjeni zaključak i preporuke |

## Podaci

Skup podataka: [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) (Kaggle)
